## 1. 产品简介

AI 驱动 Web 接口自动化测试平台是一款**零代码、AI 全自动**的接口自动化测试工具，依据产品设计与 UI 设计文档完整实现。其核心目标：让测试人员无需编写脚本，即可完成「接口导入 → 用例生成 → 批量执行 → 可视化报告 → 多格式导出」的完整测试闭环。

**核心特性**

- **多格式接口文档解析**：支持 OpenAPI/Swagger（JSON/YAML）、Postman Collection、PDF、HTML、Markdown/文本五类文档一键导入。
- **AI 智能用例生成**：对接任意 OpenAI 兼容大模型（DeepSeek / GPT / 通义千问等），按正向 / 反向 / 边界 / 异常自动生成用例；无 Key 时自动降级为内置规则引擎，保证任何环境可完整体验。
- **自动化执行引擎**：自动发请求、自动断言、超时重试、实时日志、随时终止。
- **可视化报告**：通过率、模块成功率、用例详情（请求 / 响应 / 断言 / 失败原因）一目了然。
- **多格式导出**：用例文档（Word / PDF / Excel）、测试报告（HTML / PDF / Excel）。
- **用户与权限（RBAC）**：基于角色与菜单权限的访问控制，支持多成员协作。

## 2. 环境要求

| 依赖 | 版本要求 | 说明 |
|------|----------|------|
| Python | ≥ 3.10 | 后端运行环境（推荐 3.11+） |
| Node.js | ≥ 16 | 前端构建环境（推荐 18+） |
| npm | ≥ 8 | 随 Node.js 安装 |
| 操作系统 | Windows / macOS / Linux | 无特殊限制 |
| 数据库 | SQLite（内置） | 开箱即用，可平滑切换 MySQL |
| 大模型（可选） | OpenAI 兼容 | 仅 AI 用例生成需要，未配置也可使用规则引擎 |

> 说明：平台默认使用内置 SQLite，无需额外安装数据库；AI 能力为可选增强，未配置 API Key 时不影响核心测试流程。

## 3. 安装与部署

### 3.1 方式一：一键脚本（推荐）

```bash
cd api-test-platform
bash start.sh        # Windows 用户可使用 Git Bash 执行
```

脚本自动完成：创建 Python 虚拟环境 → 安装依赖 → 构建前端 → 启动服务（含演示 Mock 接口服务）。

启动成功后访问 **http://127.0.0.1:8000**，演示账号：**admin / admin123**。

### 3.2 方式二：手动启动

```bash
# 1) 后端（FastAPI）
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cd backend && python app.py          # 监听 http://127.0.0.1:8000

# 2) 前端（开发模式，另开终端）
cd frontend && npm install && npm run dev   # http://127.0.0.1:5173

# 3) 演示接口服务（可选，用于验证执行引擎）
python mock_api.py                    # http://127.0.0.1:8099
```

> 生产模式：前端执行 `npm run build` 输出到 `web/`，由后端直接托管，访问 `http://127.0.0.1:8000` 即可使用完整系统。

## 4. 快速上手（五分钟跑通全流程）

1. **登录**：使用 `admin / admin123` 登录平台。
2. **新建项目**：进入「项目管理」，点击「新建项目」，填写名称与描述。
3. **上传接口文档**：进入项目 → 「接口管理」→「上传文档」，拖入 OpenAPI/Postman/PDF/HTML/Markdown 文档，系统自动解析并导入接口。
4. **配置测试环境**：进入「环境配置」，填写被测系统域名（Base URL）、全局请求头、超时与重试次数，并设为默认环境。
5. **AI 生成用例**：进入「AI用例生成」，选择「全项目批量」，勾选用例类型，点击「开始生成」，实时查看进度。
6. **批量执行**：进入「用例管理」或「测试执行」，选择用例与执行环境，点击「执行」，实时查看进度与日志。
7. **查看报告**：执行完成后进入「测试报告」，查看通过率、模块成功率与用例详情，支持在线查看或导出 Word / PDF / Excel。

## 5. 功能详解

### 5.1 项目管理
支持项目的增删改查、搜索；进入项目后数据自动隔离；删除有二次确认保护。

### 5.2 环境配置
支持多环境管理，配置项包括：域名（Base URL）、全局请求头（KV 动态增删）、超时时间、重试次数；默认环境高亮显示。执行用例时会自动拼接「环境域名 + 接口路径」。

### 5.3 接口文档解析
支持拖拽上传五类格式：
- OpenAPI / Swagger（`.json` / `.yaml`）
- Postman Collection（`.json`）
- PDF（文本版，由 Word/Markdown 导出）
- HTML（表格型 / 标签型）
- Markdown / 文本

解析完成后展示成功条数与失败原因。样例文档见仓库 `docs/samples/`。

### 5.4 接口管理
列表分页展示，GET/POST/PUT/DELETE 彩色标签区分；支持查看 / 编辑 / 删除 / 生成用例 / 手动录入。

### 5.5 AI 用例生成
支持单接口或全项目批量生成；用例类型可选「仅正向」或「全量（正向+反向+边界+异常）」；实时进度条与当前接口名展示，完成后给出结果统计。

### 5.6 用例管理
支持多条件筛选、优先级标记、批量执行 / 删除、单条执行；支持 AI 整理标准化用例文档并在线预览。

### 5.7 测试执行
可配置执行环境、范围、超时、重试；实时进度与统计；黑底实时日志面板；支持随时终止任务与失败重跑。

### 5.8 测试报告
报告列表、六维概览、通过率饼图、模块成功率柱状图；用例详情可展开查看请求、响应、断言与失败原因；支持 HTML / PDF / Excel 导出。

### 5.9 首页仪表盘
四宫格统计（项目 / 接口 / 用例 / 用户角色）、7 日执行趋势、用例状态饼图、最近任务快速入口。

### 5.10 系统 AI 配置
配置模型名称、API Key、BaseURL、超时，并提供连通性测试；配置后全局生效。

## 6. 用户与权限管理（RBAC）

> 入口：登录 admin → 左侧「用户与权限」。仅拥有 `users` 菜单权限的账号可见该入口。

**权限模型**

- **菜单**：功能最小权限单元，对应侧边栏入口（共 10 个）。
- **角色**：聚合一组菜单权限，可被多名用户复用。内置角色：超级管理员（全部权限）、测试工程师（测试全流程，无系统配置/用户管理）、只读访客（仅浏览）。
- **用户**：绑定角色，并可单独微调菜单权限。最终权限 = 用户自身菜单权限（优先），否则取所属角色权限。

**操作步骤**

1. 进入「角色管理」，新建角色并勾选允许访问的菜单，保存。
2. 进入「用户管理」，点击「新建用户」，填写用户名、密码（≥6 位）、昵称，选择角色；如需单独微调，展开「菜单权限」按需勾选（留空则自动继承角色权限）。
3. 保存后，该用户使用自己的账号登录，将仅看到被授权的菜单。

**安全约束**

- 内置角色不可删除；角色下仍有用户绑定时不可删除。
- 至少保留一名管理员：不能禁用 / 删除最后一个管理员，也不能修改自己的角色。
- 生产环境请务必在首次登录后修改 `admin` 默认密码。

## 7. 常见问题（FAQ）

**Q1：上传 PDF 后接口解析为空？**
A：平台仅支持**文本版 PDF**（由 Word / Markdown 导出的 PDF）。扫描件 / 图片版 PDF 无法提取文本，请改用 OpenAPI/Postman/HTML/Markdown 格式，或提供文本版 PDF。

**Q2：执行用例提示接口未拼接域名 / 请求失败？**
A：请先到「环境配置」正确填写被测系统的 Base URL 并设为默认环境；执行时也可在下拉中指定环境。执行引擎会拼接「环境域名 + 接口路径」。

**Q3：AI 用例生成没有反应 / 报错？**
A：检查「系统 AI 配置」中的 API Key、BaseURL 与模型名是否正确，并使用「连通性测试」验证；未配置 Key 时会自动降级为内置规则引擎，仍可生成用例。

**Q4：登录后左侧菜单空白 / 缺少某些入口？**
A：菜单按当前账号权限动态渲染。请以 admin 登录确认；若曾用旧后端，请**硬刷新浏览器（Ctrl/Cmd + Shift + R）并重新登录**。

**Q5：导出 Word / PDF / Excel 失败？**
A：依赖 `python-docx / reportlab / openpyxl`，请确认已执行 `pip install -r requirements.txt` 完成依赖安装。
