# 用户中心接口文档

## 用户管理

### 3.1 查询用户列表
GET /api/users

请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| page | int | 否 | 页码 | 1 |
| size | int | 否 | 每页条数 | 10 |

### 3.2 创建用户
POST /api/users

请求参数（Body）

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| username | string | 是 | 用户名 | admin |
| phone | string | 是 | 手机号 | 13800000000 |

### 3.3 删除用户
DELETE /api/users/{id}

## 鉴权模块

### 4.1 用户登录
POST /api/login

请求参数（Body）

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|---|---|---|---|---|
| username | string | 是 | 用户名 | admin |
| password | string | 是 | 密码 | 123456 |
