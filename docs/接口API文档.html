POST /api/projects/{pid}/apis/upload 上传接口文档解析 需鉴权

上传接口文档自动解析批量入库，同 method+path 自动去重。支持 5 类格式：OpenAPI/Swagger（json/yaml）、Postman Collection（json）、PDF、HTML、Markdown/文本。

路径参数
参数名类型必填默认值说明
pidinteger是-项目ID
查询参数
参数名类型必填默认值说明
filefile(binary)是-文档文件，multipart/form-data 上传，≤20MB
说明
  • Content-Type: multipart/form-data
  • 支持后缀：.json / .yaml / .yml / .pdf / .html / .htm / .md / .txt，其他后缀返回 400
  • PDF 需为文本版（Word/Markdown 导出），扫描件图片版无法提取文本
  • PDF/HTML 解析为启发式：识别「请求方法+接口路径」行或「接口名称/接口路径/请求方式」标签，并解析含「参数名/类型/必填/说明」的参数表，按 GET/DELETE→query、其余→body 归类
响应示例
{
  "code": 0,
  "msg": "接口文档解析完成，共 12 个有效接口，新增入库 9 个（重复已跳过）",
  "data": {
    "parsed": 12,
    "inserted": 9
  }
}
